# 景区导览服务 AI 数字人

面向景区游客与运营人员的智能导览系统。项目覆盖文本、语音与图片交互，将本地知识库检索、大模型生成、语音合成和数字人讲解串联为完整服务，并提供个性化路线推荐与运营分析能力。

## 技术栈

- **后端：** Java 17、Spring Boot 3.2.5、MyBatis-Plus、MySQL 8、Sa-Token、Bean Validation、SSE
- **AI 与知识库：** OpenAI-Compatible / Anthropic-Compatible 模型适配器、Embedding、MySQL 本地向量存储、余弦相似度检索
- **语音与数字人：** 阿里云 ASR / TTS、本地 Canvas 数字人渲染
- **管理端：** Vue 3、TypeScript、Element Plus、ECharts、Pinia、Vite
- **游客端：** UniApp、Vue 3、TypeScript

## 个人职责

- 负责项目后端及 AI 核心链路设计，基于 Spring Boot 3 提供标准化 RESTful API，并通过 SSE 持续推送识别文本、模型增量内容、引用来源、情绪结果和阶段耗时。
- 设计“文本/语音输入 -> 本地 RAG 检索 -> 大模型生成 -> 语音合成 -> Canvas 数字人播报”的交互链路，同时接入图片识别能力，覆盖游客问答、语音导览和景点识别场景。
- 搭建景区本地 RAG 知识库，实现文本资料入库、重叠分片、Embedding 向量化、MySQL 持久化、余弦相似度 Top-K 召回、关键词降级检索和引用溯源，提升事实问答的准确性与可验证性。
- 设计个性化路线推荐服务，根据景区、游客兴趣标签和路线类型计算匹配度，输出推荐理由、预计游览时长及有序景点列表。
- 封装大模型、视觉模型、Embedding、语音和数字人服务的统一配置能力，支持凭据加密与脱敏、连通性测试、请求超时控制及调用日志记录。
- 建设游客行为分析与运营看板，对对话和反馈数据进行情绪分类，统计热门问题、热门景点、知识库命中率、平均响应耗时和趋势数据，并支持生成分析报告。

## 核心功能

| 模块 | 能力 |
| --- | --- |
| 智能问答 | 文本与语音问答、SSE 流式响应、上下文会话、引用来源展示 |
| 本地知识库 | 文档管理、分片向量化、向量召回、关键词兜底、检索测试 |
| 多模态识别 | 图片上传、景点识别、识别结果与导览内容联动 |
| 个性化导览 | 兴趣匹配、路线排序、预计时长、推荐理由与景点顺序 |
| 语音与数字人 | ASR、TTS、音色配置、数字人形象与讲解输出 |
| 运营管理 | 景区和景点管理、会话与反馈分析、情感报告、数据大屏 |
