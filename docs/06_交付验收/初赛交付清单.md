## 当前必须补齐的基础材料

1. `assets/knowledge_raw/` 知识库素材文档（已存在，已自动导入）。
2. 基于素材整理的事实问答测试集。
3. 阿里云数字人服务口型同步验证结果（streamUrl 可播放测试）。
4. 文本大模型、多模态模型、阿里云 ASR、阿里云 TTS 的实际 API 配置（通过管理后台 AI 配置模块录入）。

## 演示主线

1. 游客打开数字人首页，看到景区化数字人欢迎语。
2. 游客语音提问景点问题，系统完成 ASR、知识库检索、LLM 回答、TTS 和数字人播报。
3. 游客拍照识别景点，系统返回识别结果并进入讲解。
4. 游客表达兴趣偏好，系统推荐个性化路线。
5. 管理员登录后台，展示知识库、AI 配置、对话记录、情绪分析和数据大屏。
6. 展示无法回答问题进入知识库补充闭环。
