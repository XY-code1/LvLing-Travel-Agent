# 景区导览服务 AI 数字人系统部署与使用手册

> 适用范围：本手册用于初赛演示环境、本机验收环境和答辩前联调。所有密钥和密码必须通过环境变量或管理后台录入，禁止写入源码。

## 1. 环境要求

| 组件 | 要求 |
|---|---|
| JDK | 17 |
| Maven | 3.9.x |
| MySQL | 8.0 |
| Redis | 7.2 |
| Node.js | 20.x |
| 包管理 | pnpm |
| 游客端 App | HBuilderX / UniApp Android 构建工具 |

## 2. 数据库初始化

1. 创建数据库：

```sql
CREATE DATABASE scenic_ai_guide DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
```

2. 执行建表和初始数据：

```powershell
mysql -u root -p scenic_ai_guide < database/schema.sql
mysql -u root -p scenic_ai_guide < database/data.sql
```

3. 初始化后应至少存在 18 张业务表，重点检查：

```sql
SHOW TABLES;
SELECT switch_key, enabled FROM demo_switch;
SELECT username, role, status FROM sys_admin;
SELECT phone, nickname, interest_tags FROM tourist_user;
```

## 3. 后端配置

PowerShell 示例：

```powershell
$env:DB_HOST='127.0.0.1'
$env:DB_PORT='3306'
$env:DB_NAME='scenic_ai_guide'
$env:DB_USERNAME='你的数据库用户名'
$env:DB_PASSWORD=Read-Host '请输入数据库密码'
$env:REDIS_HOST='127.0.0.1'
$env:REDIS_PORT='6379'
$env:REDIS_PASSWORD=''
$env:AI_CONFIG_AES_KEY='至少32位的随机字符串'
$env:FILE_UPLOAD_PATH='C:\Guido\uploads'
$env:SERVER_PORT='8080'
```

说明：

- `AI_CONFIG_AES_KEY` 用于加密 `ai_service_config` 表内的 API Key / AccessKey，必须固定保存；更换后旧密文无法解密。
- Dify、LLM、VLM、阿里云 ASR/TTS、阿里云数字人参数在管理后台“AI 配置 / 数字人配置”录入，不写入 `application.yml`。
- `FILE_UPLOAD_PATH` 需要后端进程有读写权限，游客端拍照图片和 TTS 音频会保存到该目录。

## 4. 后端启动

```powershell
cd backend
$env:JAVA_HOME='D:\JDK'
$env:Path="$env:JAVA_HOME\bin;G:\apache-maven-3.9.9\bin;$env:Path"
mvn clean package -DskipTests
java -jar target/scenic-ai-backend-0.0.1-SNAPSHOT.jar
```

启动后检查：

```powershell
curl http://localhost:8080/doc.html
```

如果 Knife4j 页面可访问，说明后端进程、端口和静态资源正常。

## 5. 管理后台启动

```powershell
cd admin-web
corepack pnpm install
corepack pnpm exec vite
```

生产构建：

```powershell
corepack pnpm build
```

管理后台主要页面：

- 登录页
- 景区 / 景点 / 路线管理
- 知识库管理与测试
- AI 配置与数字人配置
- 对话记录与待补充知识库标记
- 感受度分析报告
- 数据大屏
- 日志管理

## 6. 游客端 App 启动

游客端为 UniApp 工程：

1. 用 HBuilderX 打开 `tourist-app`。
2. 将运行环境的 API 地址配置为后端地址，例如 `http://localhost:8080` 或局域网 IP。
3. 运行到浏览器、模拟器或 Android 真机。
4. 需要 Android 包时，使用 HBuilderX 发行 Android 安装包。

游客端主要流程：

- 注册 / 登录
- 首页热门景点与推荐问题
- 创建导览会话
- 文本问答 SSE 流式回答
- 语音问答 ASR → RAG → LLM → TTS → 数字人
- 拍照识别景点并讲解
- 个性化路线推荐
- GPS 弱信号降级：GPS → 拍照定位 → 手动选点
- 个人中心兴趣标签维护
- 游客反馈

## 7. AI 服务配置

在管理后台“AI 配置”中按服务类型配置默认启用项：

| serviceType | 用途 | 关键字段 |
|---|---|---|
| `LLM` | 文本问答生成 | `protocol`, `baseUrl`, `apiKey`, `modelName` |
| `VISION` | 图片识别景点 | `protocol`, `baseUrl`, `apiKey`, `modelName` |
| `KB` | Dify 知识库 | `baseUrl`, `apiKey`, `datasetId` |
| `ASR` | 阿里云语音识别 | `accessKeyId`, `accessKeySecret`, `appKey`, `region` |
| `TTS` | 阿里云语音合成 | `accessKeyId`, `accessKeySecret`, `appKey`, `region`, `extraConfig.voice` |
| `AVATAR` | 阿里云数字人 | `accessKeyId`, `accessKeySecret`, `region` |

每一类配置保存后必须点击测试。测试成功后再设为启用和默认。

## 10. 常见故障

| 现象 | 处理 |
|---|---|
| 后端启动失败，提示数据库连接失败 | 检查 `DB_HOST/DB_USERNAME/DB_PASSWORD` 和 MySQL 是否启动 |
| 登录后接口 401 | 检查请求头是否携带 `satoken` |
| Redis 连接失败 | 检查 Redis 服务、端口和密码 |
| AI 调用提示未配置 | 在管理后台按 `serviceType` 配置默认启用项 |
| 数字人无 `streamUrl` | 检查阿里云数字人实时互动项目是否返回可播放流地址，不能用离线视频冒充 |
| 图片/音频文件无法访问 | 检查 `FILE_UPLOAD_PATH` 权限和 `/files/**` 静态映射 |
