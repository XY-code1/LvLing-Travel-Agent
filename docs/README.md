## 3. 技术选型一览

| 层 | 选型 |
|---|---|
| 游客端 | UniApp（Vue3），交付 Android APK |
| 管理后台 | Vue3 + TypeScript + Element Plus + ECharts |
| 后端 | Spring Boot 3.2.5 + JDK 17/21 + MyBatis-Plus + Sa-Token |
| 数据库/缓存 | MySQL 8.0 / Redis 7.2 |
| 知识库 | **本地 RAG**（MySQL `kb_chunk` + `LocalRagService`，余弦相似度检索），素材在 `assets/knowledge_raw/` |
| 文本/多模态大模型 | 配置式协议适配器（OpenAI-Compatible / Anthropic-Compatible） |
| 语音 | 阿里云 ASR / TTS |
| 数字人 | 阿里云数字人（实时/流式模式，返回 `streamUrl`） |
